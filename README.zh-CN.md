# Equational Challenges

[English](README.md) · [简体中文](README.zh-CN.md)

等式推理中的困难题目及其 Lean 证明集，在求解器开发过程中逐步整理形成。
错题暴露了证明搜索、反模型构造和证明生成中的不足，推动我们持续迭代 solver。
离线求解得到的证明与反模型证书统一保存在 [`proofs/`](proofs/) 中；
已解决的题目继续保留，用于检查新版本是否出现能力退化。

每道题询问：在所有 **magma**（配有一个二元运算的集合）中，一个等式是否蕴含另一个等式。
`true` 需要给出蕴含证明，`false` 需要给出反模型。蕴含方向不可颠倒。

## 错题本 3000 和 3500 是怎么来的

两套错题本**分别从 Wrong Book 2500 扩展而来**。3000 是历史名称，冻结后实际为 2,983 题。

1. **初始基准 → Candidate 2000。** 原始目录有 62,576 个等式，按表达式结构形成有向题对聚类。
   排除简单证明和小型反模型覆盖的类别后，抽取 10,000 道残余题，加上 120 道校准题形成基准。
   Candidate 2000 从中保留 1,880 道残余题（含 120 道困难配额）及全部 120 道校准题。
2. **Candidate 2118 → Wrong Book 2500。** 先追加 118 道能力探测题，再追加固定 `v97` solver
   未能解决的 382 道代表性题目，经复测修复后冻结成员。继承部分包含大量当时已能解决的题目，
   用于保留已有能力的覆盖。
3. **Wrong Book 3000 = 2,500 + 194 + 289 = 2,983。** 两批早期候选题经过多轮证明搜索和
   false solver 筛选，分别留下 194 题和 289 题。保留题目中有 9 道属于资源受限结果。
4. **Wrong Book 3500 = 2,500 + 621 + 379 = 3,500。** 642 道历史候选经筛选留下 621 道。
   另实际筛选 5,120 道新候选，证明搜索解决 4,427 道，false solver 解决 297 道，
   排除 15 道聚类重叠题后，从剩余 381 道中按结构多样性选出 379 道。

“错题”指特定版本、配置和预算下的求解失败，其中也保留了有明确记录的执行或资源异常。
它不是 true/false 标签，也不是无偏的难度排名。题目冻结后，后续 solver 解决它们时只更新结果，
不删除题目。[构建记录](docs/curation.md)保留详细筛选过程、随机种子与求解器指纹。

## 快速开始

题目采用普通 JSONL 格式，证明按有向等式对命名：

```text
datasets/wrong-book-3000/wrong-book-3000.jsonl
proofs/34_to_50568.lean
```

可以直接阅读证明。安装指定 Lean 工具链后，在本仓库根目录编译一份小证书：

```sh
lean -j 1 -M 512 proofs/34_to_50568.lean
```

仓库自带 Lean/Lake 配置：**Lean 4.33.1**，
[Mathlib 固定到 `0df444a360ea`](https://github.com/leanprover-community/mathlib4/tree/0df444a360eaa60ab8c11dca51a86af692955474)。
需要 Mathlib 的证明请先按[验证说明](docs/verification.md#lean-environment)完成一次环境安装。
使用本仓库无需另行克隆研究项目，无需求解器、私人路径或远程 Judge。
工具链和基础库首次安装需要网络，安装后可离线编译。部分证明需要更多内存，资源限制见验证说明。

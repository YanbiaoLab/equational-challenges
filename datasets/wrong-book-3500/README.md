# Wrong Book 3500

2,500 shared + 621 historical + 379 new = **3,500** frozen problems. Its 1,000-problem extension is disjoint from Wrong Book 3000.

- [wrong-book-3500.jsonl](wrong-book-3500.jsonl): frozen five-field problem data.
- [manifest.json](manifest.json): published file hash and dated solution counts.
- [Proofs](../../proofs/): one final Lean file per solved directed problem,
  named `<eq1_id>_to_<eq2_id>.lean`; its header records the verdict.

Read the [English overview](../../README.md) or [Chinese overview](../../README.zh-CN.md)
for construction and progress; [data format](../../docs/data-format.md) and
[verification](../../docs/verification.md) explain how to use and check the files.
